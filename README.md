# Space Memory

Space Memory — классическая игра на поиск одинаковых пар карточек, созданная на чистом JavaScript.

Игрок открывает по две карточки за ход и старается найти все совпадающие пары за минимальное количество ходов.

## Деплой

https://kondrati3vmaksim.github.io/memory-game/

## Возможности

- 16 карточек и 8 уникальных пар
- случайное перемешивание карточек при каждой новой игре
- счётчик ходов
- счётчик найденных пар
- анимация переворота карточек
- блокировка игрового поля во время показа несовпавшей пары
- модальное окно победы
- таблица лидеров с 10 лучшими результатами
- сохранение результатов в `localStorage`
- сортировка результатов по количеству ходов и дате
- новая игра без перезагрузки страницы
- адаптивная вёрстка
- поддержка управления с клавиатуры

## Технологии

- HTML5
- CSS3
- JavaScript
- DOM API
- Local Storage
- Fetch API

Сторонние библиотеки и фреймворки для интерфейса и игровой логики не использовались.

## Как играть

1. Откройте первую карточку.
2. Откройте вторую карточку.
3. Если изображения совпали, обе карточки останутся открытыми.
4. Если изображения различаются, карточки закроются через небольшую задержку.
5. Продолжайте игру, пока не будут найдены все 8 пар.
6. Постарайтесь завершить игру за минимальное количество ходов.

Один ход засчитывается после открытия двух разных доступных карточек.

## Таблица лидеров

После каждой победы результат сохраняется в `localStorage`.

В таблице лидеров отображаются до 10 лучших результатов.

Сортировка выполняется по следующим правилам:

1. По количеству ходов — от меньшего к большему.
2. Если количество ходов одинаковое, выше располагается более ранний результат.

Результаты сохраняются после перезагрузки страницы и повторного открытия браузера.

## Локальный запуск

Для загрузки данных карточек используется Fetch API, поэтому проект рекомендуется запускать через локальный сервер, а не открывать файл `index.html` напрямую.

Например, можно использовать расширение Live Server в VS Code.

### Запуск через Live Server

1. Склонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Установите расширение Live Server.
4. Откройте `index.html`.
5. Запустите проект через `Open with Live Server`.

## Особенности реализации

- вся разметка приложения создаётся через document.createElement
- в исходном <body> находится только тег <script>
- игровое поле генерируется динамически
- карточки перемешиваются алгоритмом Fisher–Yates
- состояние игры хранится в JavaScript
- данные карточек загружаются один раз через fetch
- новая игра не перезагружает страницу
- таймер несовпавшей пары отменяется при запуске новой игры
- модальные окна используют общую логику открытия и закрытия
