# Space Memory — игра на поиск пар

Учебный проект на чистом JavaScript. Игрок открывает две карточки за ход и ищет 8 одинаковых пар; цель — закончить игру за минимальное число ходов.

[Демо](https://kondrati3vmaksim.github.io/memory-game/) · [Исходный код](https://github.com/Kondrati3vMaksim/memory-game/tree/memory-game)

**Автор:** Максим Кондратьев. Код приложения находится в ветке `memory-game`; в `main` размещено описание.

## Технологии

JavaScript, HTML5, CSS3, DOM API, Fetch API, localStorage. Без библиотек и фреймворков. Данные карточек загружаются из локального `data.json`; отдельного backend нет.

## Что реализовал

- Создал интерфейс через `document.createElement`, сгенерировал 16 карточек из 8 записей JSON и добавил перемешивание Fisher–Yates.
- Реализовал открытие карточек, сравнение `dataset.id`, счётчики ходов и найденных пар, завершение игры.
- Добавил защиту от повторного выбора той же карточки и блокировку поля на время показа несовпавшей пары.
- Реализовал новую игру без перезагрузки страницы; при перезапуске отменяется старый таймер.
- Добавил модальное окно победы и таблицу 10 лучших результатов с сохранением в localStorage.
- Оформил адаптивный интерфейс и анимацию переворота; карточки — нативные кнопки, доступные с клавиатуры.

Основную реализацию выполнял самостоятельно. ИИ использовал как помощника для разбиения задачи на небольшие шаги.

## Как работает игра

1. Первая доступная карточка открывается и сохраняется в состоянии игры.
2. После выбора второй карточки увеличивается счётчик ходов.
3. Совпавшие карточки остаются открытыми. Несовпавшая пара закрывается через 1 секунду; до этого другие карточки не реагируют на выбор.
4. После нахождения 8 пар появляется окно победы и сохраняется результат.

Результаты сортируются по количеству ходов, затем по дате. Хранятся только в текущем браузере и не отправляются на сервер.

## Результат и выводы

Создана браузерная игра с полным циклом: новая партия → поиск пар → победа → сохранение результата. На практике связал DOM, обработчики событий, состояние игры и таймеры. Отмена таймера при перезапуске предотвращает изменение карточек предыдущей партии.

## Локальный запуск

Требования: Git, современный браузер; для варианта ниже — Python 3. npm и сборка не нужны.

```bash
git clone --branch memory-game --single-branch https://github.com/Kondrati3vMaksim/memory-game.git
cd memory-game
python3 -m http.server 8080
```

Откройте [http://localhost:8080](http://localhost:8080). Альтернатива — Live Server в VS Code. Нужен HTTP-сервер, поскольку данные загружаются через fetch; открытие `index.html` как `file://` не подходит.
